# ✈️ TripTicket

TripTicket is a **Java-based desktop/console application** designed to manage travel bookings, generate tickets, and keep track of itineraries efficiently.

## 🚀 Features
* **Ticket Management:** Create, view, and cancel trip bookings.
* **Database Storage:** Safely stores passenger and trip details.
* **User-Friendly Flow:** Clean terminal/GUI navigation for seamless operations.

## 🛠️ Prerequisites
Before running this application, make sure you have the following installed:
* **Java Development Kit (JDK):** Version 8 or higher
* **NetBeans IDE:** For importing and running the source code

## 💻 How to Run the Project
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Open **NetBeans IDE**.
3. Go to `File > Open Project` and select the cloned `tripticket` folder.
4. Click the **Run Project** button (or press `F6`).
